# Webseitenvorlage mit Dashboard

Eine neutrale Vorlage aus Website und Dashboard, die Sie herunterladen, in Ihr KI-Tool hochladen und an Ihr eigenes Unternehmen anpassen.

- **Website** nach dem Storytelling Framework: zwölf Elemente in fester Reihenfolge, dazu Impressum und Datenschutz.
- **Dashboard** nach dem 6P-Prinzip unter `/dashboard/`, geschützt durch ein Passwort: Performance (Kennzahlen aus Google Analytics), Produkt (Business Model Canvas), Positionierung (Strategie-Pyramide, Porter's 5 Kräfte, SWOT-Analyse, Persona), Promotion (Storytelling Framework), Prozess (noch offen), Plattform (Tool-Liste, inklusive Neon als mögliche Datenbank).

## So geht es los

1. Lesen Sie [die Anleitung für die Website](anleitungen/anleitung-website.md): Aufbau, Einrichten, Anpassen, Veröffentlichen.
2. Lesen Sie [die Anleitung für das Dashboard](anleitungen/anleitung-dashboard.md): die sechs Bereiche, Modelle füllen, Google Analytics verbinden.
3. Wenn Sie mit einem KI-Tool arbeiten: Laden Sie das ganze Projekt hoch und bitten Sie das Tool, zuerst [KI-UEBERSICHT.md](KI-UEBERSICHT.md) zu lesen.
